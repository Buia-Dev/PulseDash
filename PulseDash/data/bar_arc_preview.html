⭕ Conceitos de Arcos
Progressivo Crescente Tapered Sweep

A espessura da linha cresce gradualmente do início ao fim do arco, transmitindo força física, aceleração e fluxo dinâmico.

```javascript // A espessura cresce a cada segmento percorrido for (let i = 0; i < activeSteps; i++) { const stepP = i / totalSteps; const currentAng = startAng + stepP * sweepAng; const currentThickness = minThk + (maxThk - minThk) * stepP; ctx.lineWidth = currentThickness; ctx.beginPath(); ctx.arc(cx, cy, r, currentAng, currentAng + stepAng); ctx.stroke(); }```
Gradiente Cônico Conic Real

Usa um gradiente angular real que segue perfeitamente a curvatura do trajeto circular, com cores fluidas que mudam com a rotação.

```javascript // Gradiente angular HTML5 nativo const grad = ctx.createConicGradient(startAng, cx, cy); grad.addColorStop(0.0, corMin); grad.addColorStop(0.5, corMed); grad.addColorStop(1.0, corMax); ctx.strokeStyle = grad; ctx.beginPath(); ctx.arc(cx, cy, r, startAng, startAng + sweepAng * progress); ctx.stroke();```
Shift-Light Dot Matrix LED Circular

Esferas retroiluminadas que acendem de forma sequencial baseada no valor, com diâmetro crescente nas faixas mais altas (estilo F1).

```javascript // Desenha pontos discretos ao longo do arco for (let i = 0; i < totalDots; i++) { const ang = startAng + (i / (totalDots - 1)) * sweepAng; const x = cx + Math.cos(ang) * r; const y = cy + Math.sin(ang) * r; ctx.fillStyle = i < activeCount ? getCor(i) : 'rgba(255,255,255,0.05)'; ctx.beginPath(); ctx.arc(x, y, dotSize, 0, Math.PI * 2); ctx.fill(); }```
Contorno de Precisão Dual Layer

Uma trilha externa de blocos largos e intervalados emparelhada a uma linha fina interna contínua que indica a precisão.

```javascript // Desenha arco fino interno de precisão ctx.lineWidth = 2; ctx.arc(cx, cy, r - 8, startA, startA + sweepA * progress); ctx.stroke(); // Desenha blocos externos largos com intervalos for (let i = 0; i < blockCount; i++) { ctx.arc(cx, cy, r, bStart, bStart + blockLen); ctx.stroke(); }```
Segmentado Sci-Fi Dashed Grid

Arco composto de dezenas de marcações radiais (ticks) lineares e milimétricas, remetendo a mira tática ou scanner de radar militar.

```javascript // Gradiente cônico para transição suave de cores const grad = ctx.createConicGradient(startA, cx, cy); grad.addColorStop(0, color1); grad.addColorStop(0.5, color2); grad.addColorStop(1, color3); ctx.strokeStyle = grad; ctx.lineWidth = thickness; ctx.setLineDash([3, 5]); // Marcações milimétricas ctx.beginPath(); ctx.arc(cx, cy, r, startA, startA + sweepA * progress); ctx.stroke(); ctx.setLineDash([]);```
📊 Conceitos de Barras
Trapézios Inclinados Racing Segment

Segmentos de LED em formato quadrilátero inclinado paralelamente, remetendo aos displays digitais clássicos de arrancadas.

```javascript // Desenha quadriláteros com compensação de inclinação (slant) for (let i = 0; i < totalSegments; i++) { const x = startX + i * (segW + spacing); ctx.beginPath(); ctx.moveTo(x + slant, y); ctx.lineTo(x + segW + slant, y); ctx.lineTo(x + segW, y + h); ctx.lineTo(x, y + h); ctx.closePath(); ctx.fill(); }```
Chevron HUD Stack Mil-Spec HUD

Blocos em seta arqueados (V) que empilham verticalmente. Ficam progressivamente mais largos, simulando o HUD de miras táticas.

```javascript // Traça caminhos angulares (V) empilhados for (let i = 0; i < totalChevrons; i++) { const y = startY - i * (segH + spacing); ctx.lineWidth = thickness * (1 + (i * 0.05)); ctx.beginPath(); ctx.moveTo(bx, y); ctx.lineTo(bx + width / 2, y - 8); ctx.lineTo(bx + width, y); ctx.stroke(); }```
Barra Cursor Laser Laser Trail

Uma trilha minimalista ultra-fina contendo um ponto laser arredondado super brilhante e com forte glow na ponta atual da leitura.

```javascript // Linha fina de fundo, e trilha ativa com gradiente suave ctx.fillRect(bx, by, fillW, barH); // Fina // Cursor circular na ponta atual da leitura ctx.shadowColor = color1; ctx.shadowBlur = 12; ctx.arc(cursorX, by + barH/2, thk * 0.7, 0, Math.PI * 2); ctx.fill(); // Core interno branco brilhante ctx.fillStyle = '#ffffff'; ctx.arc(cursorX, by + barH/2, thk * 0.35, 0, Math.PI * 2); ctx.fill();```
Células de Fusão Fusion Cell

Blocos em formato de pílulas ou cápsulas com contornos reflexivos de vidro e um núcleo central iluminado individualmente.

```javascript // Desenha borda externa arredondada de cada célula ctx.beginPath(); ctx.roundRect(x, by, cellW, barH, 4); ctx.stroke(); // Se ativa, preenche o núcleo interno e adiciona reflexo superior ctx.beginPath(); ctx.roundRect(x + 2, by + 2, cellW - 4, barH - 4, 2); ctx.fill(); ctx.fillRect(x + 3, by + 3, (cellW - 6) * 0.45, 1.5); // reflexo```
Grade Hexagonal Honey Energy

Sequência horizontal de favos de mel (hexágonos) geométricos que se acendem individualmente, dando uma assinatura estética cibernética.

```javascript // Traça caminho poligonal de 6 vértices para cada segmento ctx.beginPath(); for (let j = 0; j < 6; j++) { const angle = (j * Math.PI) / 3; const vx = hx + Math.cos(angle) * hexSize; const vy = hy + Math.sin(angle) * hexSize; if (j === 0) ctx.moveTo(vx, vy); else ctx.lineTo(vx, vy); } ctx.closePath(); ctx.fill();```
